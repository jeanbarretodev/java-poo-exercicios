# Exercícios de POO em Java

Repositório com exercícios práticos para estudo de Orientação a Objetos em Java,
cobrindo encapsulamento, herança e polimorfismo.

## 📁 Exercícios

### 1. Controle de Carro (Encapsulamento)
Sistema de controle de um carro com marchas, aceleração e limites de velocidade.

## 🛠️ Como executar

1. Clone o repositório: `git clone <url-do-repo>`
2. Compile: `javac Main.java`
3. Execute: `java Main`

## 📚 Conceitos praticados
- Encapsulamento
- Herança
- Polimorfismo
- Princípios SOLID (parcial)
